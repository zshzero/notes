- Don't use variables with a single letter.
	- Ex - x, y, z
- Never Abbreviate the variable names as it make code harder to understand without context
	- Ex - ord instead of orders
- Don't uses Types in your variable names
	- Ex - OrderList where the type is `List<Order>`
- Add Units in your variable names When need to explicitly ask for a unit back
		- Ex: `double seconds = deplay.TotalSeconds`
- Don't naming a class with "Base" or "Abstract" and instead name your child class better 
	- Ex - `class TrailerTruck : Truck` instead of `class Truck : BaseTruck`
- Don't name code "Utils" and instead sort them into modules with good names
